# GĐ3 – Content Commerce

- **Thời lượng nêu trong nguồn:** 6–12 tháng (dự kiến).
- **Ba bước nêu trong nguồn:** Content + Lead → Affiliate/Booking → Sàn TMĐT (khi quy mô đủ lớn).
- **Tình trạng:** DRAFT; chi phí phụ thuộc **mô hình pháp lý, kinh doanh, API đối tác**.

| Mã | Bước | Module | Căn cứ |
|---|---|---|---|
| G3-01 | Lead | Liên kết nội dung với sản phẩm/dịch vụ, hồ sơ doanh nghiệp | SOURCE + PROPOSED |
| G3-02 | Lead | Form, quản lý và chuyển giao lead | SOURCE + PROPOSED |
| G3-03 | Lead | Quản lý đối tác và dịch vụ | SOURCE + PROPOSED |
| G3-04 | Affiliate | Affiliate tracking, conversion, hoa hồng | SOURCE + PROPOSED |
| G3-05 | Booking | Kết nối dịch vụ du lịch, khách sạn, vé, trải nghiệm | SOURCE + PROPOSED |
| G3-06 | TMĐT | Danh mục và quản lý sản phẩm | SOURCE + PROPOSED |
| G3-07 | TMĐT | Giỏ hàng, đơn hàng và thanh toán | SOURCE (mục tiêu TMĐT) + PROPOSED |
| G3-08 | TMĐT | Hủy/hoàn, giao hàng, hậu mãi | TBC – chỉ nếu VTV8 trực tiếp xử lý |
| G3-09 | TMĐT | Đối soát, doanh thu và hoa hồng | SOURCE + PROPOSED |
| G3-10 | B2B | Nội dung tài trợ, gói truyền thông và quảng cáo | SOURCE (kinh doanh) + PROPOSED (phân kỳ) |

## Ba kịch bản báo giá cần tách
1. **Referral/Lead:** giới thiệu nội dung, form, chuyển nhu cầu, báo cáo lead.
2. **Affiliate/Booking Integration:** kết nối đối tác, tracking, API đặt chỗ nếu có.
3. **Full Commerce:** đơn hàng, thanh toán, merchant, vận hành và đối soát.

Không mặc định kịch bản 3 là phạm vi bắt buộc ngay khi triển khai GĐ3.

## Vấn đề chờ xác nhận
- VTV8 đứng vai trò bên giới thiệu hay sàn/bên trực tiếp bán?
- Ai xử lý thanh toán, hủy/hoàn tiền, xuất hóa đơn, giải quyết khiếu nại?
- Đối tác nào có API, cơ chế đối soát/hoa hồng và SLA như thế nào?
