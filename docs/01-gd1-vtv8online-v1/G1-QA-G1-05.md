# Kiểm tra chất lượng tính năng G1-05

> **Review 09/10/2026 – chưa thay đổi baseline.** Mã tính năng không đổi; các khuyến nghị dưới đây chờ chốt để triển khai chỉnh sửa tài liệu đặc tả.

| Mã | Tính năng | Kết luận | Điều chỉnh trước ước tính |
|---|---|---|---|
| G1-05-F001 | Tải lên và tiếp nhận file media | **CHỈNH** | Giữ upload nhưng phải làm rõ file video lớn, chunk/resumable, giới hạn storage, virus scanning, định dạng và xử lý lỗi; chốt theo GĐ0. |
| G1-05-F002 | Thư viện media và tìm lọc | **GIỮ** | Giữ thư viện lọc/tìm; không mặc định chức năng DAM enterprise như duyệt asset nhiều cấp. |
| G1-05-F003 | Metadata gốc và thông tin sản xuất | **CHỈNH** | Giữ tất cả metadata nguồn VTV8 đã nêu; phân nhóm trường bắt buộc/tùy chọn để tránh nghẽn xuất bản. |
| G1-05-F004 | Quản lý quyền và thời hạn khai thác | **CHỈNH** | Giữ thông tin quyền; phân biệt ghi metadata với pháp lý xác nhận, chốt quy tắc WARN/BLOCK theo trạng thái quyền và thời điểm. |
| G1-05-F005 | Quản lý bản gốc và phiên bản xuất bản | **CHỈNH** | Giữ tham chiếu file gốc và bản phát; quản lý version lịch sử đầy đủ và pipeline tạo bản phát thuộc điều kiện/media provider. |
| G1-05-F006 | Ảnh đại diện, thumbnail và chọn file dùng trong bài | **CHỈNH** | Giữ chọn ảnh từ DAM, chỉ crop/resize thông thường nếu được chốt; không tích hợp công cụ chỉnh ảnh chuyên nghiệp. |
| G1-05-F007 | Gắn tag, nhóm và liên kết đối tượng media | **CHỈNH** | Giữ gắn tag/nhóm nhưng tái dùng dịch vụ G1-04-F009, không làm hệ phân loại media thứ hai. |
| G1-05-F008 | Thao tác xóa, lưu trữ và kiểm tra nơi sử dụng | **GIỮ** | Giữ cơ chế lưu trữ/xóa mềm bảo toàn tham chiếu; quy định thời hạn lưu file vật lý và quyền xóa. |
