# GĐ2 – Media Platform

- **Thời lượng nêu trong nguồn:** 3–6 tháng (dự kiến).
- **Mục tiêu:** làm chủ người dùng và video, phát triển VOD, tài khoản và dữ liệu xem.
- **Tình trạng:** DRAFT; các phần `PROPOSED` chưa phải yêu cầu được duyệt.

| Mã | Module | Nội dung | Căn cứ |
|---|---|---|---|
| G2-01 | IAM và tài khoản người xem | Account, login/SSO, hồ sơ, quyền riêng tư | SOURCE + PROPOSED |
| G2-02 | Cá nhân hóa trải nghiệm | Theo dõi, lịch sử, yêu thích, playlist, gợi ý | SOURCE |
| G2-03 | VOD nâng cao | Theo dõi xem dở, phụ đề, kiểm soát quyền xem | SOURCE + PROPOSED |
| G2-04 | Tìm kiếm nội dung nâng cao | Full-text, autocomplete, index/search service | SOURCE + PROPOSED |
| G2-05 | Bình luận & tương tác | Bình luận, moderation, chống spam | SOURCE (có điều kiện giấy phép) + PROPOSED |
| G2-06 | Thông báo và cập nhật | Bản tin, push notification, lịch thông báo | SOURCE + PROPOSED |
| G2-07 | Subscription, Paywall, DRM | Thuê bao, quyền xem, thanh toán tích hợp, DRM | SOURCE + PROPOSED |
| G2-08 | Analytics hành vi | Sự kiện xem, dashboard, thống kê user/video | SOURCE + PROPOSED |
| G2-09 | Nâng cấp Media & QoE | Chất lượng phát, monitor, SLA, scaling | SOURCE + PROPOSED |

## Điều kiện phụ thuộc
- Phải dùng lại Content, DAM, VOD, Live từ GĐ1; tránh báo giá xây lại.
- Chưa rõ mô hình ID/SSO, gói trả phí, DRM/license và điều kiện pháp lý tương tác.
- Cần xác định khối lượng event, chính sách lưu giữ và mức độ cá nhân hóa.

## Ngoài phạm vi mặc định
AI semantic search sâu, ecommerce/booking, partner portal và native app; chuyển sang giai đoạn sau.
